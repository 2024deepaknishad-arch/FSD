# CyberAudit 360 — Experiment 1 (Tailwind CSS, React)

```bash
npm install
npm run dev
```

Pure UI skeleton in React + Tailwind: Landing, Login, Dashboard, Sidebar, Navbar, Cards,
Tables — all with hardcoded/static data, no hooks or Context state yet. This is the
exact project Experiment 2 (`useEffect`, `useContext`, custom hooks) and Experiment 3
(Context API global state) get built on top of — same file/folder names throughout.
